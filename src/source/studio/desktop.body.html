What’s new

Studio ships a new release every few weeks. Here are the latest.

All releases
Oct 20, 2026 FlutterFlow Studio

Widget Tree, AI Agent Plans & Firebase SDKs

Open the widget tree while your app runs in Test Mode, watch the AI Agent tick off its plan as it works, and keep the agent on the branch that you have open. Generated apps move to current Firebase SDKs, and support for the retired Firebase Dynamic Links service is removed.

Read the release notes Widget Tree, AI Agent Plans & Firebase SDKs
Oct 14, 2026 FlutterFlow Studio

Device Previews, Swagger Import & AI Agent Images

Preview pages on the latest phones and foldables, review Swagger and OpenAPI changes endpoint by endpoint before you import them, and send images to the AI Agent. This release also fixes how Dynamic Links open on iOS, in in-app browsers, and in social apps.

Read the release notes Device Previews, Swagger Import & AI Agent Images
Oct 6, 2026 FlutterFlow Studio

Flutter 3.47, Dynamic Links & Test Mode Logs

FlutterFlow 7.2 moves your projects to Flutter 3.47.1 and replaces Firebase Dynamic Links with FlutterFlow Dynamic Links. Test Mode gets a Logs panel that can send layout overflows to the AI Agent, and built-in widgets get an Additional Flutter Properties section.

Read the release notes Flutter 3.47, Dynamic Links & Test Mode Logs
